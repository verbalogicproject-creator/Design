# Synth tab design (Creation Studio)

Source files for the design canvas: https://claude.ai/artifact/TenhEpHfsgjfcZCFYDTySJ

- `canvas.json` lays out every board. `*.dc.html` files are the boards and reusable parts.
- `synth.css` holds the tokens ("console and scribble strip") and shared component styles.
- `tokens.json` lists colour, spacing, radius and depth tokens for developers.
- Rows on the canvas: library and system; phone screens; landscape and plugin; desktop; parts; flows (Sing, automation); product gaps (first run, settings, project, sheets, errors).
